# 怪猎世界伤害计算器 · MHW Damage Calculator

用于《怪物猎人：世界 / 冰原》的配装伤害计算器。核心用途是把**会心流配装**和**攻击流配装**放在一起对比，看一眼就知道哪套期望伤害更高。

纯单文件网页，离线可用，无需安装任何依赖。

## 在线使用

启用 GitHub Pages 后可直接访问：

```
https://<你的用户名>.github.io/<仓库名>/
```

也可以把 `index.html` 下载到本地，双击用浏览器打开。

## 功能

- **双配装并排对比**：配装 A（会心流）与配装 B（攻击流），同一目标下直接比较期望伤害
- **非会心 / 会心 / 期望**三种伤害分别给出，物理与属性分开计算
- **部位肉质**：内置 38 只大型怪物、每只 5–28 个部位的切断 / 打击 / 遥远 / 火水雷冰龙肉质
- **斩味倍率**：红橙黄绿蓝白紫，物理与属性分别套用
- **会心体系**：基础会心、看破、弱点特效（肉质 ≥45 触发）、超会心 Lv0-3、会心击【属性】/ 真·会心击【属性】
- **软化模拟**：开启后按 `0.75 × 肉质 + 25` 重算肉质
- **怪物补正**：可手动填入怒后 / 防御倍率
- 可选属性类型（无 / 火 / 水 / 雷 / 冰 / 龙）与额外攻击力、攻击力百分比、额外属性值，用于覆盖挑战者、无击等未内置技能

## 计算公式

```
真实攻击力 = 显示攻击力 ÷ 武器倍率 + 攻击技能固定值 + 额外攻击力
实际攻击力 = 真实攻击力 × (1 + 攻击技能百分比 + 自定义百分比)

物理伤害 = 实际攻击力 × (动作值 ÷ 100) × 斩味物理倍率 × (肉质 ÷ 100) × 会心倍率 × 怪物补正
属性伤害 = (显示属性值 ÷ 10 + 额外属性值) × 斩味属性倍率 × (属性吸收 ÷ 100) × 属性会心倍率 × 怪物补正
```

**会心倍率**：正会心 1.25，超会心 Lv1/2/3 提升到 1.30 / 1.35 / 1.40；负会心 ×0.75。

**期望伤害**

- 会心率 ≥ 0：`非会心 × (1 − 会心率) + 会心 × 会心率`
- 会心率 < 0：`非会心 × (1 − |会心率|) + 非会心 × 0.75 × |会心率|`

**属性会心**：会心击【属性】×1.35，真·会心击【属性】×1.55，仅在会心命中时对属性部分生效。

**弱点特效**：仅在对应肉质 ≥45 时生效（Lv1/2/3 → 会心率 +10 / +15 / +30）。

需要 Node.js（测试用，构建只依赖 PowerShell）。

```powershell

powershell -ExecutionPolicy Bypass -File tools\build.ps1

# 数值测试：932 个「怪物 × 部位 × 配装」组合
node tools\test.js index.html
```

## 已知取舍

- 红斩 / 橙斩的**物理**倍率采用社区通用表的 1.00。部分中文资料写作 0.5 / 0.75，实际输出几乎不会停留在红斩，影响可忽略。
- 属性会心只对属性部分生效，物理会心仍按超会心表计算。
- 软化同时应用于物理与属性肉质，且统一使用 `0.75 × 肉质 + 25`；部分怪物（如溟波龙、麒麟）有 ±5 的个体差异，未单独建模。
- 动作值（MV）需手动输入，未内置各武器招式表。
